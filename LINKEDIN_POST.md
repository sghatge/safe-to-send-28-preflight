Safe to Send · Ep 28 — 28 days, 28 repos, one command

Safe to Send: 28 episodes on governing AI in CRM operations, one open-source repo each, synthetic data only.

This repo pulls it together: preflight. One command, five gates:
1. Policy: did the agent try anything it must never do?
2. QA: is the email itself right?
3. Lock: does the AI-written summary tell the truth?
4. Approvals: who has to sign?
5. Audit: is every result recorded so nobody can quietly change it?

Croatia: GO, two approvers needed.
Greece: NO-GO. A blocked delete, a blocked export, English price format, a 23:30 send, and a summary that called it "ready to send".

What I'm taking away:
→ In CRM, the hard part of AI isn't the model. It's the guardrails, the tests and the shared standards around it.
→ Rules decide. Models explain. Tests prove it.
→ Standardise before you automate.
